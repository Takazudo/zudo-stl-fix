## Live VoiceOver (issue #1 row)

VoiceOver was turned on with ⌘F5. Its first-run welcome dialog was answered with
**Use VoiceOver**. Navigation used VoiceOver's own commands (VO-arrows, VO-Shift-Down/Up
to interact, VO-Space to activate). The spoken text was read from VoiceOver's
caption panel after each step (`macos-arm64-2026-11-08-voiceover-captions.png`).
An attempt to read speech through VoiceOver's AppleScript interface timed out, so
the captions are the record.

| Element | VoiceOver output |

| Drop group | "Drop local STL files here to check and conservatively repair, group" |
| Choose Files | "In Drop local STL files here…, group Choose Files…, button" |
| Import message | "notes.txt: Choose a local STL file." then "Dismiss, button" |
| Rows | "<name> <full path>, <status>, <warning>…": Saved, Checked — review needed, Error with reason, Cannot repair safely, Repair ready |
| Row actions | "Save…, button", "Reveal, button", "Details, button", "Remove nuts-v2-60hp-double.stl, button" |
| Warnings | "4 triangles have altitude < 1e-5 coordinate units (not a wall thickness measurement)", "Geometry extends below Z=0; placement unchanged" |
| Bottom controls | "Advanced, collapsed, disclosure triangle"; "Clear Finished, button"; "Save Fixed Files…, button" |
| Advanced toggle | VO-Space → "expanded", again → "collapsed" (AX value 1 / 0) |
| Details sheet | Heading and status, then inside the text element VO-Down reads line by line: Warnings, the warning, "Triangles: 1710 → 1692", "Invalid triangle pairs: 62 → 0", dimensions, bounds. Then "Export JSON Report…, button" and "Done, default, button". VO-Space on Done closed the sheet |

Observation, not changed: each row is announced with its full original path,
because the file name carries the path as help text. This is verbose but
accurate.

VoiceOver was turned off afterwards. The temporary `SCREnableAppleScript` key was
removed. VoiceOver's own first-run defaults (braille tables) remain in its
preference domain.
