title: zudo-stl-fix
description: A local macOS app that checks STL files and conservatively repairs them.
sidebar_position: 0
---

zudo-stl-fix is a native macOS utility: drop STL files, check them, conservatively repair what can be repaired, and save verified copies. Everything runs locally.

Repair is deliberately limited. Unsupported geometry is refused rather than guessed, and a valid mesh is not proof that a model is printable.
