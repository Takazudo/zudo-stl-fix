## Where to start

zudo-stl-fix is a macOS drag-and-drop app (SwiftUI) that runs a Python geometry engine in a separate bundled helper process. These pages cover how to build it, how it is tested, how CI is arranged, and what has and has not been verified.

- To build the app, read [Building on macOS](./building-macos.mdx).
- To run the checks, read [Testing](./testing.mdx).
- For the workflows, read [Continuous integration](./ci.mdx).
- For an honest account of what passed, read [Verification status](./verification-status.mdx).

:::note
Verification on macOS is only partly complete. [Issue #1](https://github.com/Takazudo/zudo-stl-fix/issues/1) tracks the remaining checks, and nothing on these pages claims they have passed.
:::
