Technical reference for how zudo-stl-fix is put together and what its engine promises. The native macOS app and the CLI share one Python geometry engine; the app runs it in a separate helper process.

:::info[Pending macOS verification]
This reference describes the implemented source. Compiling, packaging and running the native app on macOS are verified separately and are still pending; follow [issue #1](https://github.com/Takazudo/zudo-stl-fix/issues/1) for their status.
:::
