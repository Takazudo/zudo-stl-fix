Technical reference for how zudo-stl-fix is put together and what its engine promises. The native macOS app and the CLI share one Python geometry engine; the app runs it in a separate helper process.

:::info[Supported platform]
The native app supports macOS 27 or later on Apple silicon (arm64) only. Its build, packaging and packaged-app behavior have been verified on that platform; see [Verification status](../develop/verification-status.mdx).
:::
