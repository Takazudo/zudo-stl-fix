## No public release yet

There is currently **no public, signed, or notarized release** of zudo-stl-fix. To run the app you build it yourself on a Mac. A locally built app is ad-hoc signed and is not notarized, so Gatekeeper asks you to confirm opening it on first launch.

## Build locally

On a Mac with the documented toolchain (see the [Develop section](../develop/index.mdx) for prerequisites, pinned dependencies, and exact commands):

```sh
make test-app
make package-local
```

`make package-local` builds a real `.app` bundle with an architecture-matched frozen helper, checks the nested code, exercises the relocated helper, and creates a local archive. The only product is arm64; there is no universal2 or x86_64 build.

Open the resulting `zudo-stl-fix.app` to start the app.

## Requirements

- macOS 27 or later on an Apple silicon (arm64) Mac. Older macOS versions and Intel Macs are not supported; macOS 27 does not run on Intel Macs.
- The built app needs no user-installed Python, Homebrew, account, or network connection.

:::tip
Only want to repair STL files from a terminal? The [CLI section](../cli/index.mdx) covers the Python engine without the app.
:::
