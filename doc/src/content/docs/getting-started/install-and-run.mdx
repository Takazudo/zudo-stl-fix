## Download

1. Open the [latest release](https://github.com/Takazudo/zudo-stl-fix/releases/latest) and download `zudo-stl-fix-<version>-macos-arm64.zip`.
2. Unzip it (double-click in Finder) and move `zudo-stl-fix.app` to `/Applications`.
3. Open the app. The first time, macOS blocks it: dismiss the dialog, then go to **System Settings → Privacy & Security** and click **Open Anyway**.

The release build is ad-hoc signed only. It is **not** Developer ID signed or notarized, which is why macOS asks once before opening it.

To check the download, put the `.sha256` file from the same release next to the zip and run `shasum -a 256 -c zudo-stl-fix-<version>-macos-arm64.zip.sha256`.

## Build locally

To build the app yourself instead, on a Mac with the documented toolchain (see the [Develop section](../develop/index.mdx) for prerequisites, pinned dependencies, and exact commands):

```sh
make test-app
make package-local
```

`make package-local` builds a real `.app` bundle with an architecture-matched frozen helper, checks the nested code, exercises the relocated helper, and creates a local archive. The only product is arm64; there is no universal2 or x86_64 build.

Open the resulting `zudo-stl-fix.app` to start the app.

## Requirements

- macOS 27 or later on an Apple silicon (arm64) Mac. Older macOS versions and Intel Macs are not supported; macOS 27 does not run on Intel Macs.
- The app needs no user-installed Python, Homebrew, account, or network connection.

:::tip
Only want to repair STL files from a terminal? The [CLI section](../cli/index.mdx) covers the Python engine without the app.
:::
