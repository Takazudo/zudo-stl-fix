zudo-stl-fix がどのように構成され、そのエンジンが何を保証するかについての技術リファレンスです。ネイティブの macOS アプリと CLI は 1 つの Python ジオメトリエンジンを共有しており、アプリはそれを別のヘルパープロセスで実行します。

:::info[サポート対象のプラットフォーム]
ネイティブアプリがサポートするのは Apple silicon（arm64）上の macOS 27 以降だけです。そのプラットフォームで、ビルド、パッケージング、パッケージ化したアプリの動作を検証済みです。[検証状況](../develop/verification-status.mdx)を参照してください。
:::
