## 公開リリースはまだありません

現時点で zudo-stl-fix には、**公開リリース、署名済みリリース、公証（notarize）済みリリースのいずれもありません**。アプリを使うには、Mac 上で自分でビルドする必要があります。ローカルでビルドしたアプリはアドホック署名で、公証されていないため、開く際に macOS から確認を求められることがあります。

## ローカルでビルドする

ドキュメントに記載されたツールチェーンを備えた Mac で、次のコマンドを実行します（前提条件、固定された依存バージョン、正確なコマンドについては [Develop セクション](../develop/index.mdx)を参照してください）。

```sh
make test-app
make package-local
```

`make package-local` は、アーキテクチャに合わせてフリーズしたヘルパーを含む実際の `.app` バンドルをビルドし、内包するコードを検査し、配置後のヘルパーを実際に動かして確認したうえで、ローカル用のアーカイブを作成します。アーカイブにはビルドしたマシンのアーキテクチャ名が付きます。universal2 ビルドはありません。

できあがった `zudo-stl-fix.app` を開くとアプリが起動します。

## 動作要件

- 想定している最小デプロイ対象は macOS 14 です。ただし macOS 14 上での実行テストはまだ行っておらず、これまでに確認できたのは Apple silicon 上のより新しい macOS での動作のみです。[issue #1](https://github.com/Takazudo/zudo-stl-fix/issues/1) を参照してください。
- ビルドしたアプリは、ユーザーが別途インストールした Python、Homebrew、アカウント、ネットワーク接続のいずれも必要としません。

:::tip
ターミナルからSTLファイルを修復できれば十分という場合は、アプリを使わずに Python エンジンを利用する方法を [CLI セクション](../cli/index.mdx)で説明しています。
:::
