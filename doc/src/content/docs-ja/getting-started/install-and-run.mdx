## 公開リリースはまだありません

現時点で zudo-stl-fix には、**公開リリース、署名済みリリース、公証（notarize）済みリリースのいずれもありません**。アプリを使うには、Mac 上で自分でビルドする必要があります。ローカルでビルドしたアプリはアドホック署名で、公証されていないため、初回起動時に Gatekeeper から確認を求められます。

## ローカルでビルドする

ドキュメントに記載されたツールチェーンを備えた Mac で、次のコマンドを実行します（前提条件、固定された依存バージョン、正確なコマンドについては [Develop セクション](../develop/index.mdx)を参照してください）。

```sh
make test-app
make package-local
```

`make package-local` は、アーキテクチャに合わせてフリーズしたヘルパーを含む実際の `.app` バンドルをビルドし、内包するコードを検査し、配置後のヘルパーを実際に動かして確認したうえで、ローカル用のアーカイブを作成します。成果物は arm64 だけで、universal2 や x86_64 のビルドはありません。

できあがった `zudo-stl-fix.app` を開くとアプリが起動します。

## 動作要件

- Apple silicon（arm64）の Mac で macOS 27 以降。それより古い macOS と Intel Mac はサポート対象外です。macOS 27 は Intel Mac では動作しません。
- ビルドしたアプリは、ユーザーが別途インストールした Python、Homebrew、アカウント、ネットワーク接続のいずれも必要としません。

:::tip
ターミナルからSTLファイルを修復できれば十分という場合は、アプリを使わずに Python エンジンを利用する方法を [CLI セクション](../cli/index.mdx)で説明しています。
:::
