## 詳細

任意の行の **Details** をクリックすると、次の情報を含むシートが開きます。

- ステータスとメッセージ（ある場合）
- 警告
- 修復前後の三角形の数と、修復前後の不正な三角形ペアの数
- STL座標単位で表記した寸法とバウンディング範囲
- 連結したシェルの数、向きを直した面の数、頂点の移動量、バイナリ書き出し時の量子化、バウンディング範囲の変化
- エンジンのバージョンと、エラーの理由（ある場合）

STLファイルには単位の指定がないため、寸法に「mm」と表記することはありません。シートには、メッシュの検証が造形可能性、強度、寸法の適合、シェルの包含関係を保証するものではないという注意も表示されます。

## Export JSON Report

詳細なレポートがある場合、シートに **Export JSON Report…** が表示されます。フォルダを選ぶと、そこに `<original-stem>-report.json` を保存します。保存するファイルと同じく上書きしない命名規則（`-report-2.json` など）が使われます。結果やエラーは行に表示されます。

レポートには、面IDや交差の詳細など、シートに表示するには長すぎる大きなリストが含まれます。
