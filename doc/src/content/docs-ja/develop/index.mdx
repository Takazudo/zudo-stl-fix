## はじめに読むページ

zudo-stl-fix は、Python のジオメトリエンジンを別プロセスのバンドル済みヘルパーとして動かす、macOS 向けのドラッグ＆ドロップアプリ（SwiftUI）です。このセクションでは、ビルド方法、テストの仕組み、CI の構成、そして検証済みの項目と未検証の項目を説明します。

- アプリをビルドするには、[macOS でのビルド](./building-macos.mdx)を読んでください。
- チェックを実行するには、[テスト](./testing.mdx)を読んでください。
- ワークフローについては、[継続的インテグレーション](./ci.mdx)を読んでください。
- 何が通ったかの正確な記録は、[検証状況](./verification-status.mdx)にあります。

:::note
macOS での検証はまだ一部しか完了していません。残りのチェックは [Issue #1](https://github.com/Takazudo/zudo-stl-fix/issues/1) で管理しており、これらのページではそれらが通ったとは一切主張していません。
:::
