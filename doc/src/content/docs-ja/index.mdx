sidebar_position: 0
---

zudo-stl-fix は macOS 向けのネイティブユーティリティです。STLファイルをドロップしてチェックし、修復できるものだけを保守的に修復して、検証済みのコピーを保存します。処理はすべてローカルで行われます。

修復の範囲は意図的に限定されています。対応できない形状は推測せずに拒否します。また、メッシュが有効であることは、造形可能であることの証明にはなりません。
